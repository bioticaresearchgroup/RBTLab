{% comment %} LIST RENDERER (generic) The workhorse for rendering collections. Reads a data source either from _data/include.data or from site.collection (site[include.data]), groups entries by year (newest first), and for every item calls an include.component (e.g. card, citation, portrait) passing every field as a named param. Optional include.filter pre-filters the items via the data_filter plugin.
